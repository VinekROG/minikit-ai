# Changelog

All notable changes to `minikit-ai` are recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] — 2026-09-29

First public release.

### Added

- Local retrieval-augmented generation (RAG) over PDF, Word, Markdown and plain
  text documents, with embeddings and answer generation running entirely on the
  local machine through Ollama.
- Web dashboard served on the loopback interface only, using Go templates,
  HTMX and Server-Sent Events for token streaming.
- Command-line interface: `serve`, `index`, `query`, `doctor`, `clear`,
  `security-test`, `version`.
- Anti-exfiltration middleware: every outbound connection is forced through a
  dialer that accepts only the loopback address. A violation wipes the
  in-memory session and is written to an audit log.
- In-process self-test that deliberately attempts to reach `1.1.1.1` and
  `example.com` so the user can verify the guarantee themselves.
- Per-user Windows installer requiring no administrator rights, which preserves
  the document corpus on uninstall.
- Panel hardening: per-session token authentication, `Host` header validation
  against DNS rebinding, per-client rate limiting, a ceiling on concurrent
  generations, request-body and question-length caps, a strict
  `Content-Security-Policy`, and a hosted-demo mode that disables every feature
  able to touch the host filesystem.
- Web assets encrypted with AES-256-GCM inside the executable and decrypted into
  memory at run time.
- Documentation in seven languages.

### Known issues

- The installer is not code-signed, so Windows SmartScreen warns on first run.
- The document database is not encrypted at rest.
- Answers are generated by a deliberately small model and can be wrong; the cited
  passages should always be checked.
