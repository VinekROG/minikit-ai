# minikit-ai

> 向你自己的文档提问。不上传任何东西。不让任何数据离开你的电脑。

[English](README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Português](README.pt.md) · [中文](README.zh.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md)

**Windows 10/11** · 无需管理员权限 · 单个安装包 · 断网也能用。

## 1. 这是什么

让它指向一个文档文件夹。它会读取、记住这些文档，并用日常语言回答关于它们的问题 ——
同时把用到的原文段落展示给你。

- 支持 **PDF**、**Word (.docx)**、**Markdown** 和**纯文本**
- 全部在你自己的电脑上运行：AI 模型、数据库、网页面板
- 无需账号、无需 API 密钥、无需订阅、无任何遥测

## 2. 四步安装

### 第 1 步 — 安装 Ollama

Ollama 是免费开源的引擎，用来在你自己的电脑上运行 AI 模型。

1. 打开 **<https://ollama.com/download>**
2. 下载 Windows 版本并安装
3. 保持安装即可，暂时不用手动启动。

### 第 2 步 — 下载两个 AI 模型

打开**命令提示符**（按 `Win` 键，输入 `cmd`，回车），把下面两行**分别**粘贴执行：

```
ollama pull nomic-embed-text
ollama pull qwen2.5:0.5b
```

- `nomic-embed-text`（274 MB）把文字转换成数字，让程序能够检索
- `qwen2.5:0.5b`（400 MB）负责生成回答

它们刻意做得非常小 —— 目标是在老旧、廉价的电脑上也能跑。如果你的内存更大、想要更好的
回答，之后可以换成 `qwen2.5:3b`。

### 第 3 步 — 运行安装程序

1. 打开 **<https://github.com/OWNER/minikit-ai/releases/latest>**
2. 下载 `minikit-ai-0.1.0-setup.exe`（约 4 MB）
3. 双击运行
4. Windows 会显示一个蓝色警告。这是正常的，见下方说明。
5. 点击**更多信息 → 仍要运行**
6. 安装程序**从不**要求管理员权限

> **关于蓝色警告：** Windows 显示它是因为该文件没有数字签名。作者没有代码签名证书。
> 警告内容是"未知发布者"，不是"病毒"。安装完成后，这个提示只出现一次。

### 第 4 步 — 启动程序

1. 按 Windows 键，输入 **minikit-ai**
2. 回车
3. 会弹出一个黑色小窗口，浏览器自动打开
4. 这就是程序本身。黑色窗口必须保持打开。

## 3. 使用方法

1. **添加文档。** 把文件拖进窗口，或者输入文件夹路径，例如
   `C:\Users\你\Documents\contracts`，然后点*索引*。
2. **提问。** 在右边的输入框里用任何语言提问。
3. **核对来源。** 回答会列出它用到的段落，方便你核实。

第一次回答会比较慢（老电脑上 30–90 秒），因为模型要第一次载入内存。之后的回答快得多。

支持的格式：`.pdf` `.docx` `.txt` `.md`

## 4. 为什么你的文档是私密的

这是最重要的部分。下面是程序**实际**的机制，而不是一句承诺。

### 4.1 网络是物理关闭的

程序发出的**每一次**对外连接都要经过唯一一道关口。这道关口只允许一个目标：
`127.0.0.1`，也就是你自己的电脑。没有别的。不允许网址，不允许域名，不允许你局域网里的
其他设备。

如果有任何东西试图向外连接 —— 编程错误、损坏的文件、藏在你某份文档里的恶意指令 ——
会同时发生三件事：

1. 连接被拒绝。
2. 内存中的文档数据被覆写为零。
3. 该尝试被写入你可以在面板里查看的日志。

你随时可以自己验证。点击面板上的**执行自检**按钮：它会故意尝试访问 `1.1.1.1` 和
`example.com`，并把被拒绝的结果显示给你。

### 4.2 别人无法远程使用你的副本

面板只绑定在你的机器上，每次启动都会生成一个随机密码，拒绝来源地址不是本机的请求，
并且在有人短时间内发送过多请求时不再响应。另一个标签页里打开的网页无法与它通信。

### 4.3 源代码不公开

本仓库只包含安装程序和文档。**源代码不在这里。** 如果你想了解它是怎么实现的，需要当面
谈 —— 那不是你能从网上直接复制走的东西。

### 4.4 界面在程序内部是加密的

面板的 HTML、CSS 和 JavaScript 以加密形式存储在可执行文件中，只在运行时于内存中解密。
用文本编辑器打开文件，或者解压程序，都看不到它们。

## 5. 诚实的局限

对你坦诚，比一个漂亮的宣传页面更有价值。

| | |
|---|---|
| **没有数字签名** | Windows 第一次会警告：`更多信息 → 仍要运行`。 |
| **数据库没有加密** | 文档保存在你用户目录下的一个文件里。能访问你 Windows 账户的人就能读取。 |
| **它只会引用，不会推理** | 它查找并复述文档里的内容，不会计算或推导。 |
| **回答可能出错** | 模型刻意做得很小。请始终核对引用的段落。 |
| **一次一个用户** | 为一个人、一台电脑设计，不是共享服务器。 |

## 6. 常见问题

**需要联网吗？**
只在安装和下载模型时需要。之后你可以断网，它照常工作。

**会向任何公司发送数据吗？**
不会。程序在物理上做不到：它唯一接受的联网目标是 `127.0.0.1`。第 4.1 节解释了原因，
也说明了如何验证。

**怎么卸载？**
设置 → 已安装的应用 → minikit-ai → 卸载。文档会被保留而不是删除，所以以后重装不会
丢失索引。

**我的电脑很慢，怎么办？**
提问时关闭其他程序。第一次回答总是最慢的。

**出问题了怎么办。**
打开命令提示符，输入 `minikit-ai doctor`。它会准确告诉你缺少什么。
