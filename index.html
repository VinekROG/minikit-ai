What it does

You point it at a folder of documents — PDFs, Word files, Markdown, plain text. It reads them, splits them into chunks, and computes a numeric fingerprint for each chunk using a local AI model. Later you type a question in normal language; it finds the passages that matter and writes an answer citing them.

All of that happens on your machine. There is no account, no API key, no upload and no subscription.

Why it is hard for anyone else to copy

ThreatWhat stops it
A web page you have open reads your documentsBlocked
A site tricks the program into talking to the internetBlocked
Someone copies the source codeNot published
Someone extracts the interface from the binaryEncrypted
Your data sits readable in a folderNo — see below

Every outbound connection is intercepted by a gate that only allows the local loopback address. If anything — a dependency, a poisoned document, a bug — even tries to reach the outside, the connection is refused, the in-memory session is wiped and the attempt is written to an audit log. It is not a setting you can forget to turn on.

Honest limits

  • The installer is not code-signed, so Windows SmartScreen will warn you the first time. Click More info → Run anyway. It is unsigned because the author has no signing certificate.
  • The database of your documents is a plain file in your user folder. It is protected by your Windows account, not by encryption.
  • It is a search tool, not a reasoning engine. It quotes what your documents say.
  • Answers can be wrong. Always check the cited passages.

Install in four steps

1.  Install Ollama          https://ollama.com/download
2.  Download two models      ollama pull nomic-embed-text
                             ollama pull qwen2.5:0.5b
3.  Run the installer        minikit-ai-0.1.0-setup.exe   (no admin needed)
4.  Launch it                Start menu → minikit-ai

The browser opens automatically. Drop a file in, ask a question.

For developers

The source code is not part of this repository. If you want to study or reuse the implementation, the author is open to discussing it.
